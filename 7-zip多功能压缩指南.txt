一、 环境准备与依赖配置（新电脑只需配置一次）
------------------------------------------------------------
1. 安装 Python 环境：
   - 必须提前安装 Python v3.6+ 版本才能正常运行此脚本。
   - Python 官方网站：https://www.python.org/

2. 安装 7-Zip 软件：
   - 必须安装 7-Zip 才能正常压缩文件。
   - 7-Zip 官方网站：https://www.7-zip.org/
   - 中文镜像站：https://sparanoid.com/lab/7z/
   - 脚本会自动搜索以下默认安装路径：
       C:\Program Files\7-Zip\7z.exe
       C:\Program Files (x86)\7-Zip\7z.exe
       D:\Data\7-Zip\7z.exe
   - 若您的 7z.exe 不在以上位置，可打开脚本，在 find_7zip() 函数中
     的 sevenzip_paths 列表里添加您的自定义路径。

3. 安装 tqdm 进度条依赖库：
   - 本脚本为了模拟和显示真实进度，需要添加 tqdm 依赖库。
   - 安装方法：按键盘 Win + R 键，输入 cmd 然后按回车。
   - 在弹出的命令提示符中，输入并运行指令：pip install tqdm
   - 如果上述命令无法识别，可尝试输入：python -m pip install tqdm
   - 验证安装：输入指令 python -c "import tqdm; print('tqdm 安装成功！')" 查看结果。

4. tqdm库安装失败常见问题解决：
   - 问题1：提示 "pip 不是内部或外部命令"。
     - 解决方案：确保 Python 已正确安装，并且必须勾选添加到 PATH（环境变量）。
   - 问题2：提示 "权限不足"。
     - 解决方案：鼠标右键使用管理员权限运行命令提示符，或者使用命令：pip install --user tqdm
   - 问题3：网络问题导致下载超时。
     - 解决方案：在命令后面加上国内镜像源地址进行加速。

二、 全局控制参数配置（在脚本 main() 位置修改）
------------------------------------------------------------
打开脚本文件，可以在底部的 "def main():" 位置直接更改默认初始配置：
- FILE_LIST_PATH：指定你默认需要压缩的文件列表路径（如 r"D:\视频\filelist.txt"）。
- COMPRESS_LEVEL：指定全局默认压缩等级，范围为 "0~9"。

★ 全局压缩等级（0~9）说明：
  0 ：仅存储（不压缩，只进行归档打包）
  1 ：极速压缩（速度最快，体积最大）
  3 ：快速压缩
  5 ：标准压缩（推荐平衡点）
  7 ：最大压缩
  9 ：极限压缩（体积最小，耗时最长）

三、 压缩模态与操作指南（1~13 菜单功能）
------------------------------------------------------------
本合集脚本启动后，会通过菜单选项供您选择一种具体的压缩模式：

【A. 本地当前目录快速模态】
  * 将脚本放入需要压缩的文件夹内，双击运行即可。
  1 - 单独压缩为 ZIP 格式（每个文件单独分包，不包含子文件夹）。
  2 - 单独压缩为 7Z 格式（每个文件单独分包，不包含子文件夹）。
  3 - 批量分离分包压为 ZIP 格式（每个文件/子文件夹单独分包，保持原有目录结构）。
  4 - 批量分离分包压为 7Z 格式（每个文件/子文件夹单独分包，保持原有目录结构）。

【B. 外部 TXT 文件列表集群模态】
  * 压缩前需手动创建 "filelist.txt" 文本文件（文件名可随意，注意路径对应）。
  * 在脚本同目录下（或任意位置）手动创建一个文本文件（如 filelist.txt），
    每行写入一个需要压缩的文件或文件夹的完整绝对路径，例如：
    D:\视频\电影1.mp4
    D:\文档\重要资料
    ★ 重要：路径可以带引号（单引号或双引号均可），脚本会自动去除首尾引号，
      也可以不带引号，按真实路径即可。每行一个路径，换行分隔。
  * 在脚本启动后，通过菜单选项 11 指定该文本文件的路径，或在脚本的 FILE_LIST_PATH
    变量中预设默认路径。
  5 - 使用文件列表 - 单独压缩纯文件（格式为 ZIP）。
  6 - 使用文件列表 - 单独压缩纯文件（格式为 7Z）。
  7 - 使用文件列表 - 批量分离压缩（包含列表内的文件夹和文件，格式为 ZIP）。
  8 - 使用文件列表 - 批量分离压缩（包含列表内的文件夹和文件，格式为 7Z）。

【C. 高强度防爆破三重套娃模态】
  * 旨意进行三重交替压缩，文件包内保持完整的原有目录结构，文件名保持为源文件名。
  9 - 三重套娃压缩（流程为：原始文件/文件夹 -> ZIP -> 7Z -> ZIP）。
  10 - 三重套娃压缩（流程为：原始文件/文件夹 -> 7Z -> ZIP -> 7Z）。
  * 特技：三重压缩过程中会产生临时中间文件（如第一次生成的 ZIP，第二次生成的 7Z），
    每完成一步，脚本会自动删除上一步产生的临时压缩包，只保留最终成品。
    源文件始终保留（除非在启动前开启了“删源联动”模式）。

【D. 系统级全局控制参数】
  11 - 在控制台内直接重新指定外部文本文件列表（txt）的读取路径。
  12 - 动态修改全局压缩等级（可在 0~9 级之间实时重构）。
  13 - 安全关闭并退出程序。

四、 特色高阶功能
------------------------------------------------------------
★ 联动删源（谨慎使用）：运行任意压缩模式（1~10，包括两种三重套娃模式）时，
   均可在压缩开始前选择是否启用“压缩后自动删除源文件”。
   开启后，每个文件或文件夹压缩成功后，脚本会调用系统删除命令将其彻底删除
  （不可恢复，请务必在操作前确认数据已备份）。
   特别提醒：对于三重套娃模式（9/10），您还可以进一步选择删除时机：
     - 选项1：第一步压缩完成后立即删除原始文件（空间释放更快，但中途无法再使用原始文件）
     - 选项2：全部三步压缩完成后统一删除原始文件（更安全，全程可保留原始文件）
   临时中间文件（ZIP/7Z）在每步完成后照常自动清理，仅保留最终成品压缩包。
★ 明细全显：所有模式在真正封包前，都会扫描并打印出待处理清单与合并总大小。
★ 失败追踪：若因权限或文件占用导致封包失败，会自动抓取 7-Zip 原生错误日志供排查。
