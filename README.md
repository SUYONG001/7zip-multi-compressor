## 一、 环境依赖与配置（只需配置一次）

### 1. Python 运行环境
* **版本要求**：Python 3.6 及以上。
* **官方下载**：[Python 官方网站](https://www.python.org/)
* **注意事项**：Windows 安装时务必勾选 **`Add Python to PATH`**（自动配置环境变量）。

### 2. 7-Zip 压缩软件
* **官方下载**：[7-Zip 官网](https://www.7-zip.org/) | [中文镜像站](https://sparanoid.com/lab/7z/)
* **路径检索**：脚本启动时会自动探测以下常见安装路径：
  ```text
  C:\Program Files\7-Zip\7z.exe
  C:\Program Files (x86)\7-Zip\7z.exe
  D:\Data\7-Zip\7z.exe
  ```
* *若安装在非标准路径，可在脚本内搜索 `find_7zip()` 函数，在 `sevenzip_paths` 列表中直接追加自定义安装路径。*

### 3. 安装 `tqdm` 进度条依赖库
用于调用 7-Zip 底层 `-bsp1` 参数并实时渲染真实进度条。

按快捷键 Win + R 输入 `cmd` 打开命令行，执行：
```bash
pip install tqdm
# 若提示命令未识别，尝试：
python -m pip install tqdm
```

**快速验证安装：**
```bash
python -c "import tqdm; print('tqdm 安装成功！')"
```

#### 常见安装报错与处理
| 故障现象 | 排查原因 | 解决方案 |
| :--- | :--- | :--- |
| `pip 不是内部或外部命令` | Python 未加入环境变量 | 重新运行 Python 安装包，选择 **Modify** 并勾选 **Add Python to PATH** |
| `Permission denied`（权限不足） | 目标目录需要提权 | 鼠标右键“以管理员身份运行”CMD，或执行：`pip install --user tqdm` |
| 下载极慢 / 网络超时 | 默认源连接受阻 | 挂载国内镜像源加速：`pip install -i [https://pypi.tuna.tsinghua.edu.cn/simple](https://pypi.tuna.tsinghua.edu.cn/simple) tqdm` |

## 二、 全局预设参数说明

在脚本末尾的 `def main():` 函数区域，可直接修改全局初始预设值：

```python
def main():
    COMPRESS_LEVEL = 5                      # 默认全局压缩等级（0~9）
    FILE_LIST_PATH = r"D:\视频\filelist.txt"  # 默认读取的文件列表路径
```

### 全局压缩等级（0~9）对照表
| 压缩等级 | 内部参数 | 压缩比 | 处理速度 | 资源开销 | 推荐场景 |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **0** | `-mx=0` | 无 | 极快（仅受磁盘写入限制） | 极低 | 仅做文件归档/打包，不进行压缩 |
| **1** | `-mx=1` | 偏低 | 极快 | 较低 | 追求打包效率、传输带宽充裕时 |
| **3** | `-mx=3` | 适中 | 快 | 较低 | 日常快速备份 |
| **5** | **`-mx=5`** | **良好** | **均衡（默认推荐）** | **适中** | **压缩率与用时的最佳平衡点** |
| **7** | `-mx=7` | 较高 | 较慢 | 较高 | 需进一步缩小体积且 CPU 性能良好时 |
| **9** | `-mx=9` | 极限 | 最慢 | 极高（高内存/CPU占用） | 追求最小磁盘占用、长期冷备份 |

## 三、 压缩功能模态详解（1~13 菜单）

### 模态 A：本地当前目录快速模态（1~4）
> **操作方式**：将脚本直接放置在待压缩的文件所在文件夹内，双击运行即可。

* **`1` - 单独压缩为 ZIP**：遍历当前目录下所有文件，逐个独立打包为 `.zip`（**忽略子文件夹**）。
* **`2` - 单独压缩为 7Z**：遍历当前目录下所有文件，逐个独立打包为 `.7z`（**忽略子文件夹**）。
* **`3` - 批量分离打包为 ZIP**：当前目录下所有纯文件和子文件夹**独立切分分包**，保持各子目录内部完整结构。
* **`4` - 批量分离打包为 7Z**：当前目录下所有纯文件和子文件夹**独立切分分包**，保持各子目录内部完整结构。

---

### 模态 B：外部 TXT 文件列表集群模态（5~8）
> **操作方式**：跨盘符、跨目录批量处理。需提前建立一个纯文本列表（如 `filelist.txt`）。

#### 文件列表规范示例
每行填入一个需要处理的完整绝对路径（支持单/双引号，脚本会自动规整首尾符号）：
```text
D:\视频\影片A.mp4
D:\文档\重要项目备份
"E:\Download\Raw Data"
```

* **`5` - 列表处理 · 纯文件单独打包 (ZIP)**：仅打包列表内的文件，自动跳过文件夹。
* **`6` - 列表处理 · 纯文件单独打包 (7Z)**：仅打包列表内的文件，自动跳过文件夹。
* **`7` - 列表处理 · 批量分离混合打包 (ZIP)**：同时处理列表中的文件夹与文件，逐一独立封装。
* **`8` - 列表处理 · 批量分离混合打包 (7Z)**：同时处理列表中的文件夹与文件，逐一独立封装。

---

### 模态 C：高强度防和谐三重套娃模态（9~10）
通过交替变换封装算法实现多重防御。全程保持原本的目录结构与原始文件名。

#### 流程说明
* **模式 9**：原始文件/目录 -> **ZIP** -> **7Z** -> **ZIP（最终成品）**
* **模式 10**：原始文件/目录 -> **7Z** -> **ZIP** -> **7Z（最终成品）**

```text
[原始数据] ──(第1步)──> [临时包 A] ──(第2步)──> [临时包 B] ──(第3步)──> [★ 最终成品包]
                           │                     │
                           └── 自动清理销毁 ─────┴── 自动清理销毁
```
> **自动清理机制**：每完成一层嵌套，脚本会自动安全销毁上一步骤产生的临时压缩介质，磁盘最终仅保留最终成品包。

---

### 模态 D：系统级全局控制参数（11~13）
* **`11` - 重新指定外部文件列表路径**：在不重启脚本的前提下，直接输入挂载新的 `txt` 清单路径。
* **`12` - 动态重构压缩等级**：即时调整全局压缩强度（`0~9`），立即对后续所有压缩操作生效。
* **`13` - 安全退出**：释放系统资源并正常关闭交互窗口。

## 四、 核心高阶机制与安全策略

### 1. 联动删源（空间释放与安全控制）
执行任一压缩模态（1~10）前，均会弹出空间策略确认。

> **⚠️ 关于全自动删除源文件**：删除操作直接调用系统级永久删除（文件/文件夹不可通过回收站还原）。请务必确认源数据已有完备备份。

针对**三重套娃模态（9/10）**，特别设计了两级删除时机控制：
* **时机 1：第一步压缩完成后立即删除原始文件**  
  * **优点**：最快释放磁盘占用，避免因源文件与中间包共存导致磁盘爆满。
  * **代价**：若后续第 2、3 步因故异常中断，无法再次基于原始文件重试。
* **时机 2：全部三步封装完成后统一删除原始文件（推荐）**  
  * **优点**：容错率最高，全程保留底稿直至最终成品校验通过。

### 2. 明细预检与容量预估
任何压缩任务正式触发调用前，控制台均会自动扫描全部目标，汇总打印清单明细及换算后的人性化总大小（B / KB / MB / GB / TB），便于操作前核对。

### 3. 底层原生错误捕获
若由于文件句柄被占用、文件损坏或系统权限不足导致封包中断，脚本会自动抓取 7-Zip 原生错误输出流末尾的关键日志并高亮标出，告别黑盒盲猜排查。
